# Date-filter calibration microbenchmark

This is a cheap two-stage engineering scenario for calibrating the harness and
scenario rubric. A subject extends a tiny existing standard-library Python JSONL
report with inclusive lower and upper date filters.

The scenario can expose requirement completion, documentation consistency,
behavioral test quality, scope discipline, robustness, and process cost. It is
not representative evidence for architecture, sustained collaboration, or
orchestration. The matrix therefore contains direct Codex arms only.

`contracts.json` defines pass/fail requirements and separately records unscored
robustness probes. `rubric.json` contains the scenario-specific qualitative
anchors. Run one repetition first as plumbing evidence before approving the
declared three-repetition calibration matrix.
