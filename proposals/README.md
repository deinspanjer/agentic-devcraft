# Proposed skills

Everything below this directory is unreleased and may change or be removed based
on evaluation. Comparison declarations reference these sources directly.

Each candidate has one source directory shared by Claude and Codex evaluation.
Promotion moves that directory into `plugins/agentic-devcraft/skills/`; it does
not create host-specific copies. The marketplaces publish only the shared plugin
payload, so a proposed skill cannot leak into a release before promotion.
