# Cold read

Before finalizing a conclusion that depends on checkable repository facts:

1. Enumerate every load-bearing claim, including sibling conclusions that reuse
   the same premise.
2. Read the primary source cold. Record each claim as observed, inferred, or
   unknown, with the exact evidence that supports that status.
3. Re-evaluate the conclusion and its dependent siblings when a material claim
   fails.

Preserve the user's chosen workflow and output format. Complete the check only
when every material claim has a status and every changed premise has been
propagated to the conclusions that depend on it.
