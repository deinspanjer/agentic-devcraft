---
name: evidence-before-complexity
description: Check whether added machinery is needed and keep one-time requests scoped before expanding a change.
---

Before adding machinery beyond the requested change, identify the concrete
condition that would make it necessary and check the available evidence.
Use the existing, simpler path when it satisfies the request.

If a material uncertainty remains, ask a focused question. Before adding a
new mode, gate, or workflow that materially expands scope—even when evidence
supports it—explain the need and simpler alternative, then ask the user.

Keep one-time review requests scoped to that occasion. Verify the requested
outcome, including dependencies needed for it to work.
