## Why

Devcraft needs objective evidence that its skills improve agent behavior without adding false findings, workflow conflicts, or disproportionate overhead. Before those comparisons are credible, the project needs a repeatable way to launch authenticated Claude Code and Codex agents, converse with them, and provision the exact skill or toolkit under test in an isolated environment.

## What Changes

- Scaffold Harbor as the first evaluation runner and pin the version proven by the bootstrap suite.
- Authenticate Claude Code with a subscription OAuth token generated by `claude setup-token`, and authenticate Codex through Harbor's native `CODEX_AUTH_JSON_PATH` upload of the user's ChatGPT-authenticated `auth.json` into a disposable agent home.
- Support both one-shot CLI execution and persistent conversations driven by scripted turns or a testing agent.
- Add a minimal test-subject lifecycle that installs, configures, verifies, invokes, and tears down a declared skill, workflow, or toolkit in a clean agent environment.
- Establish installation-and-use smoke tests for the Devcraft status skill, Superpowers, GSD, the Pocock skill collection, OpenSpec, and Spec Kit across Claude Code and Codex where each subject supports the host.
- Record unsupported host/subject combinations explicitly rather than silently skipping or treating them as passing.
- After bootstrap, add paired control and treatment trials for review integrity, cold factual verification, decision evolution, explicit workflow ownership, and Peters Toolkit coexistence.
- Use direct skill or hook injection for later content-focused comparisons when installation behavior is not under test.
- Keep candidate Devcraft skill sources under `proposals/skills/` while they are under evaluation; only the shared `plugins/agentic-devcraft/skills/` payload is published by the Claude and Codex marketplaces.

## Capabilities

### New Capabilities

- `devcraft-evaluation`: Defines authenticated, isolated Harbor trials and repeatable comparisons of Devcraft skills and hooks across supported coding agents and workflow contexts.

### Modified Capabilities

None.

## Impact

- Adds Harbor configuration, test-subject definitions, smoke fixtures, behavioral fixtures, verification logic, and result artifacts under this repository.
- Exercises locally authenticated Claude Code and Codex installations inside disposable Harbor environments and requires Docker plus the model endpoints and source hosts declared by each test.
- Adds an in-container authentication preflight; an unavailable, expired, or incorrectly mounted credential blocks that host's trial without exposing credential contents.
- Does not release candidate skill behavior. Marketplace or canonical installer behavior is exercised only by bootstrap smoke tests that declare it; behavioral fixtures reference the unreleased source directly.
